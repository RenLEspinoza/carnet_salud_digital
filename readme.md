# Carnet Salud Digital (CSD v1) 🐾

Plataforma web para clínicas veterinarias que permite digitalizar el historial clínico de mascotas y generar carnets públicos accesibles mediante código QR.

## Stack Tecnológico

- **Backend:** Node.js, Express, PostgreSQL, Sequelize ORM, JWT, Multer + Cloudinary.
- **Frontend:** Vanilla JavaScript (ES Modules), Vite, Tailwind CSS.
